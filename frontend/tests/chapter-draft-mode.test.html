Chapter Draft Mode - Manual Test

Test Instructions

  1. Make sure you're logged in as an author
  2. Go to your Dashboard
  3. Select a fanfic
  4. Go to the "Capítulos" tab
  5. Click "Novo Capítulo"

Test Cases

✅ Test 1: Draft Checkbox Visible

Expected: The chapter form should have a checkbox labeled "Salvar como Rascunho"

✅ Test 2: Create Draft Chapter

Steps:
  1. Fill in chapter title and content
  2. Check the "Salvar como Rascunho" checkbox
  3. Click "Criar Capítulo"
Expected: Chapter should be created with a "📝 Rascunho" badge

✅ Test 3: Publish Button Visible for Draft

Expected: Draft chapters should show a "📢 Publicar" button

✅ Test 4: Publish Draft Chapter

Steps:
  1. Click the "📢 Publicar" button on a draft chapter
  2. Confirm the action
Expected:
  • Draft badge should disappear
  • Publish button should disappear
  • Success notification should appear

✅ Test 5: Draft Hidden from Readers

Steps:
  1. Create a draft chapter
  2. Log out or open in incognito mode
  3. View the fanfic detail page
Expected: Draft chapter should NOT appear in the chapter list for non-authors

✅ Test 6: Draft Visible to Author

Steps:
  1. As the author, view the fanfic detail page
Expected: Draft chapter should appear with "📝 Rascunho" badge

✅ Test 7: Edit Draft Status

Steps:
  1. Edit a published chapter
  2. Check the "Salvar como Rascunho" checkbox
  3. Save changes
Expected: Chapter should become a draft and show the draft badge
