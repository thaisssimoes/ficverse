Test 2: Tag Addition

Instructions:

  1. Open the form using the button above
  2. Try adding tags in each category (fandom, warning, pairing)
  3. Verify that you can add up to 5 tags per category
  4. Verify that the 6th tag shows an error message
  5. Verify that you can remove tags by clicking the × button

Test 3: Tag Autocomplete

Instructions:

  1. Open the form
  2. Type at least 2 characters in any tag input field
  3. Verify that autocomplete suggestions appear
  4. Click on a suggestion to add it as a tag

Test 4: Cover Image Validation

Instructions:

  1. Open the form
  2. Try uploading an invalid file type (e.g., .txt, .pdf)
  3. Verify that an error message appears
  4. Try uploading a valid image (JPG, PNG, GIF, WEBP)
  5. Verify that no error appears

Test 5: Form Validation

Instructions:

  1. Open the form
  2. Try clicking "Publicar" without filling required fields
  3. Verify that validation errors appear
  4. Fill in Title, Synopsis, and Category
  5. Verify that you can now save as draft or publish

Test 6: Content Warnings

Instructions:

  1. Open the form
  2. Check the "Conteúdo Adulto (+18)" checkbox
  3. Add text to the "Trigger Warnings" rich text editor
  4. Verify that both fields are properly styled and functional

Test 7: Draft vs Publish

Instructions:

  1. Open the form
  2. Fill in only the Title field
  3. Click "Salvar como Rascunho"
  4. Verify that it allows saving with minimal fields
  5. Try clicking "Publicar" with only Title filled
  6. Verify that it requires Synopsis and Category
